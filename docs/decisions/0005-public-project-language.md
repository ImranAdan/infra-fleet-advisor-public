# PDR 0005: Public project language

**Status:** Accepted
**Date:** 2026-09-14

## Decision

Public entry points lead with Infra Fleet's staging platform and Infra Fleet
Advisor's intent-driven repository review. They describe inputs, configuration,
evidence, and human review rather than advertising the projects as
"secret-free" or categorically holding no credentials.

Credential boundaries remain architectural discussion in decision records.
Operational guides retain the concrete configuration and permission scopes
needed for each optional integration. This language change does not alter the
read-only analysis contract, registered checks, publication permissions, or
approval gates.
